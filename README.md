# 📰 Automated VnExpress News Ingestion & AI Summarizer

[![AI-Model](https://img.shields.io/badge/Model-Google%20Gemini-orange.svg)](https://ai.google.dev/)

[![Hosting](https://img.shields.io/badge/Deployment-GitHub%20Pages-brightgreen.svg)](https://Lan-Anh-12.github.io/vnexpress-crawler-summarizer/)

An end-to-end automated data pipeline that continuously crawls and parses RSS news feeds from VnExpress, leverages the Google Gemini API to produce concise abstractive summaries, synchronizes structured records with Supabase (PostgreSQL), and serves an updated static frontend deployed via GitHub Pages.
